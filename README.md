# ✨ 말씀의 빛, 세상으로 — 말씀 묵상 앱

> 분홍 버전(`../mountain-path-pink`)을 복사해 **앱 색상 5가지(주황·하늘·보라·분홍·초록)** 를 고를 수 있게 하고, ‘나의 길’ 산을 고정 시점·지그재그 길·여러 색·나무와 구름으로 꾸민 앱입니다. 기기 저장소(`mountain-path-color`)와 개발 포트(5178)가 따로라 다른 두 앱과 기록이 섞이지 않아요. 백업 파일은 서로 주고받을 수 있어요.

주일 설교 본문을 월~금 5일로 나눠 묵상하고, 한 주씩 3D 산길을 오르는 모바일 우선 웹앱.
(campus-drama를 바탕으로 만들었습니다)

---

## 🙏 성도 안내

1. 앱 주소를 휴대폰 브라우저로 열고 **‘홈 화면에 추가’**를 누르면 앱처럼 쓸 수 있어요.
2. 처음에 이름과 카드 모양(기본 / 크게 보기)을 고릅니다.
3. **오늘** — 그날의 본문(개역한글)을 읽고 묵상 카드를 씁니다. 0.5초마다 자동 저장돼요.
   - 기본: 관찰 · 해석 · 적용 · 기도
   - 크게 보기(시니어 모드): 마음에 남은 말씀 · 기도 한 줄
4. **나의 길** — 주일마다 정거장이 하나씩 생기는 산길. 묵상한 날은 돌이 빛나고, 아바타가 내가 묵상한 주까지 올라가요.
5. **목장** — 이번 주 나눔 질문과, 내가 고른 칸(관찰·해석·적용·남은 말씀)만 담은 글을 복사해 카카오톡에 붙여 넣어요.
6. **가정예배** — 이번 주 본문으로 만든 순서지. 인쇄도 돼요.
7. **🎨 꾸미기**(하단 메뉴) — 어느 화면에서나 앱 색상(주황·하늘·보라·분홍·초록), 글꼴(주아·고운돋움·나눔고딕·나눔명조·기본), 글자 크기(보통~아주 크게 4단계), 시니어 모드, 🎵 배경음악을 바로 바꿔요.
   - 배경음악은 각자 휴대폰의 음악 파일을 골라 그 기기에만 저장해요(저장소·백업·나눔 글에 들어가지 않음). 교회가 사용 허락을 받은 곡이 있으면 `public/config.json` 의 `bgmUrl`·`bgmTitle` 에 넣어 기본 곡으로 쓸 수 있어요.
   - 목장 나눔의 **💬 카카오톡으로 나누기**: 휴대폰은 공유 창에서 카카오톡을 고르면 나눔 글 전체가 그대로 가고, PC는 글을 복사해 붙여 넣어요. 목장방이 오픈채팅이면 링크를 넣어 ‘복사하고 목장방 열기’로 바로 열 수 있어요. 기도 칸은 여기에도 들어가지 않아요.
8. **더보기** — 위 설정과 함께 이름, 아바타, 백업·복원.

글꼴은 Google Fonts 의 Jua·Gowun Dodum·Nanum Gothic·Nanum Myeongjo(모두 SIL Open Font License)와 Pretendard 를 씁니다.

### 🔒 기도는 나만 봐요
- 기도 칸은 목장 나눔·공유·복사·인쇄 어디에도 들어가지 않습니다.
- 유일한 예외는 **내 기기 백업 파일**입니다. 백업 파일은 다른 사람에게 보내지 마세요.
- 모든 묵상은 **내 기기 브라우저 안에만** 저장되고 서버로 보내지 않아요. 기기를 바꾸기 전에 **더보기 → 백업 저장**을 해 두세요.

## 📝 담당자: 주일 설교 올리는 법

1. 앱 **더보기 → 설교 등록(담당자)** 에서 날짜(주일)·제목·본문 범위·설교자를 입력합니다.
   - 본문 범위 예: `요한복음 15:1-17`, `요 15:1~17`, `요한복음 15:1-16:4`, `시편 23`
   - 월~금 본문이 자동으로 나뉘고, 칸을 고쳐 직접 나눌 수도 있어요. (5절 미만이면 같은 본문을 5일 동안 묵상)
2. **이 기기에 저장 · 미리 보기** → 내 기기에서만 먼저 확인할 수 있어요.
3. **sermons.json 내려받기** → 저장소의 `public/sermons.json`을 이 파일로 바꿔 올리면, 배포 후 모든 성도에게 반영됩니다.

`sermons.json` 항목 형식:
```json
{ "id": "2026-11-15", "date": "2026-11-15", "title": "산 위에서 주신 복",
  "passage": "마태복음 5:1-16", "preacher": "담임목사",
  "groupQuestions": ["..."], "familyQuestion": "..." }
```

**매일 묵상 계획**(토·주일 포함, 한 주에 책이 바뀌어도 됨)은 `days`에 요일별 본문을 넣습니다.
`weekday`는 월=1 … 금=5, 토=6, 주일=7이고, 날짜는 `date`(그 전 주일) + weekday 일입니다.
`days`가 있으면 `passage`는 화면에 보이는 글일 뿐이라 자유롭게 적어도 돼요.
```json
{ "id": "2026-11-15", "date": "2026-11-15", "title": "고린도후서 12–13장 · 시편 20–22편",
  "passage": "고린도후서 12:1 – 시편 22:31", "preacher": "",
  "days": [ { "weekday": 1, "ref": { "book": 47, "from": { "c": 12, "v": 1 }, "to": { "c": 12, "v": 13 } } }, "…",
            { "weekday": 7, "ref": { "book": 19, "from": { "c": 22, "v": 22 }, "to": { "c": 22, "v": 31 } } } ] }
```
담당자 화면에서도 요일 칸을 고치거나 ‘+ 토요일 추가’로 7일까지 늘릴 수 있어요.

## ⚙️ 교회 이름·로고 (나중에 설정)

`public/config.json` 만 고치면 됩니다. 다시 빌드할 필요 없어요. 비워 두면 화면 어디에도 나오지 않습니다.
```json
{ "appName": "산에 오르는 길", "tagline": "한 주의 말씀을 따라 한 걸음씩",
  "churchName": "", "logoUrl": "", "sermonsUrl": "./sermons.json", "contactNote": "" }
```
로고는 `public/logo.png`처럼 넣고 `"logoUrl": "./logo.png"`로 적으세요.

## 🛠 개발

```bash
npm install
npm run dev      # http://localhost:5178 (포트 고정: 브라우저 저장 데이터가 주소별로 따로 저장됨)
npm test         # 본문 분할·기도 비공개 테스트 (vitest)
npm run build
```

`main` 브랜치에 push하면 `.github/workflows/deploy.yml`이 GitHub Pages로 배포합니다. (HashRouter + `base: './'`)
